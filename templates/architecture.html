Architecture Highlights:

  • Cloud VM (Compute Tier): Amazon EC2 running Linux, Nginx, and Python Flask knowledge management engine.
  • Object Storage (Storage Tier): Amazon S3 with server-side AES-256 encryption and folder prefixes isolating HR, IT, and Sales files.
  • Security & IAM Tier: No hardcoded AWS credentials; VM assumes an IAM Instance Profile. Bucket policies strictly deny lateral movement.
  • Audit Monitoring Tier: Dual-destination audit engine recording all access attempts locally and streaming to AWS CloudWatch Logs.

IAM Architecture

IAM User & Group Configuration

IAM Group: HR-Department-Group

Policy: Attached hr_group_policy.json. Permits s3:* on hr/* & shared/*; explicitly denies it/* and sales/*.

IAM Group: IT-Department-Group

Policy: Attached it_group_policy.json. Permits s3:* on it/* & shared/*; explicitly denies hr/* and sales/*.

IAM Group: Sales-Department-Group

Policy: Attached sales_group_policy.json. Permits s3:* on sales/* & shared/*; explicitly denies hr/* and it/*.

IAM Role: EC2-S3-KBAccess-Role

Assumed by the EC2 VM Instance Profile. Mediates fine-grained access without storing long-lived static AWS access keys on the server.
